# NovaOS 17 PC 🏔️

**An open-source project bringing Android 17 to desktop and laptop computers.**

## About NovaOS

NovaOS 17 PC is an independent operating system project based on Android 17 (AOSP), designed to bring the original Android experience to x86_64 computers.

The project focuses on adapting Android for PC hardware while preserving its native interface, functionality, and overall user experience.

## Project Goals

- Run Android 17 on desktop and laptop computers.
- Preserve the original Android Quickstep Launcher.
- Support system navigation, notifications, and Android applications.
- Improve compatibility with PC hardware, including keyboards, mice, and displays.
- Provide a bootable ISO for testing and installation.
- Keep the project open source and accessible to the community.

## Development Status

**Pre-Alpha — Under Active Development**

NovaOS 17 PC is currently undergoing development, debugging, and testing.

The first planned release is **Alpha 1.0**. A publicly tested release is not yet available.
