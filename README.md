# NovaPC 1 🏔️

**Android 17 for PCs & Laptops.**

An open-source operating system project bringing the Android experience to desktop and laptop computers.

## About NovaPC

**NovaPC 1** is an independent operating system project based on **Android 17 (AOSP)**, designed for x86_64 desktop and laptop computers.

NovaPC aims to deliver the native Android experience on PC hardware while preserving Android's original design, functionality, and user experience.

The project combines the familiar Android interface with features and optimizations designed specifically for computers.

## Project Goals

- Bring Android 17 to desktop and laptop computers.
- Preserve the native Android Launcher3 and Quickstep experience.
- Support Android applications, gestures, notifications, and system navigation.
- Improve compatibility with keyboards, mice, touchpads, and displays.
- Introduce **Nova Features** for additional system customization.
- Support customizable boot animations and system appearance.
- Provide bootable ISO images for testing and installation.
- Keep the project open source and accessible to everyone.

## Nova Features

NovaPC introduces its own customization features while maintaining the original Android experience.

### Boot Animation Customization

Choose from different boot animation styles, including:

- Android (AOSP)
- Google Pixel (where available and permitted)
- NovaPC
- Custom boot animations

### System Customization

Nova Features is a dedicated section within Android Settings for additional personalization, animation controls, appearance options, and system-specific settings.
